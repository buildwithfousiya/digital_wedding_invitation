# Wedding Invitation - Sharafali & Fasna

A beautiful, single-page wedding invitation website created for Sharafali and Fasna.

## Features
*   **Opening welcome screen / loader card**: Gold text design with Arabic Bismillah and an auto-dismiss transition.
*   **Live Countdown**: Displays remaining days, hours, minutes, and seconds.
*   **Interactive background music**: Mute/unmute floating toggle button.
*   **Responsive layout**: Optimized for all desktop and mobile devices.
*   **Interactive Location Map**: Features a map screenshot of PCM Auditorium Valiyora and a button linking to Google Maps.
